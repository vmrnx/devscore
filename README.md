# Tabela do Brasileirão - CI/CD

Projetocriado para a disciplina de DevOps.
Consome a [API-Futebol](https://www.api-futebol.com.br/) para exibir a classificação em tempo real.

## Como rodar localmente
1. Crie uma conta gratuita na API-Futebol.
2. Copie o seu Token de Teste.
3. Cole o token na variável `TOKEN` dentro do arquivo `app.js`.
4. Abra o arquivo `index.html` no seu navegador.
